Bundled theme fonts, all SIL OFL 1.1. Pixelify Sans and Fredoka are
fallbacks for the Minecraft and Terraria themes, used only when the game
fonts (Minecraft, Minecrafter, Andy) are not installed.
- Pixelify Sans (via @fontsource/pixelify-sans) - Minecraft theme
- Fredoka (via @fontsource-variable/fredoka) - Terraria theme
- Kavoon (via @fontsource/kavoon) - Tiki theme headings
- Shippori Mincho B1 (via @fontsource/shippori-mincho-b1) - Ink Wash theme headings
- Literata (via @fontsource-variable/literata) - Ink Wash theme script text
- IM Fell English (via @fontsource/im-fell-english) - Cyanotype theme headings
- Newsreader (via @fontsource-variable/newsreader) - Cyanotype theme script text
- Courier Prime (via @fontsource/courier-prime) - Card Catalog theme script text and headings
- Special Elite (via @fontsource/special-elite, Apache License 2.0, not OFL) - Card Catalog theme stamps
- Bricolage Grotesque (via @fontsource-variable/bricolage-grotesque) - Riso Zine theme
- Grenze Gotisch (via @fontsource-variable/grenze-gotisch) - Spellbound theme title
- Almendra (via @fontsource/almendra) - Spellbound theme headings
- EB Garamond (via @fontsource-variable/eb-garamond) - Spellbound theme script text
- Potta One (via @fontsource/potta-one) - Ronin theme headings
- Yusei Magic (via @fontsource/yusei-magic) - Ronin theme script text and UI
